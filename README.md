# 🐶 Random Dog Image Fetcher

## Description
The **Random Dog Image Fetcher** is a simple web application that fetches and displays random dog images using the [Random Dog API](https://random.dog/). The project demonstrates how to make HTTP requests using Axios in a React or Node.js environment.

---

## Features
- 🐕 **Fetch Random Dog Images**: Get a new dog image every time you click a button.
- ⚡ **Efficient API Call**: Uses Axios to fetch data from the API asynchronously.
- 📱 **Responsive Interface**: Display images in a clean and responsive layout.

---

## Technologies Used
- **Frontend**: React.js (or Vanilla JavaScript if you used plain JS)
- **HTTP Client**: Axios
- **Styling**: CSS or Tailwind CSS (if used)
